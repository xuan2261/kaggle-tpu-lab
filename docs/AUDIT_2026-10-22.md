## Remaining acceptance gaps

1. **Kaggle account/ToS:** verify the user's own allowed local model list, real remaining AI Models quotas, and suitability for their proposed usage. Never post a model proxy token in GitHub or chat.
2. **Live protocol:** separately test small authorized calls against the actual Model Proxy for OpenAI Chat, Responses, Anthropic Messages, tool-use, SSE, token expiry and quota reporting. A mock PASS is not a live PASS.
3. **TPU sessions:** start/stop/reattach Qwen and GLM on an authorized real Kaggle TPU if desired; confirm Cloudflare tunnel's actual behavior. No evidence exists yet for a stable, long-running API.
4. **Windows installer and ACL:** install/run the actual Companion on Windows and verify profile save/read, tray, credential file DACL and reconnection. The successful Rust unit tests do not prove GUI acceptance.
5. **Supply chain:** audit Rust transitive dependencies, consider action SHA pinning and signed Windows installer processes before a release.
6. **Release governance:** keep PR #3 and any audit-fix PR in Draft until the above evidence and a manual review. Do not force-push or auto-merge `main`.
